Как работает контурный хитбокс: Алгоритм обходит пиксели спрайта по альфа-прозрачности (Marching Squares / Moore-Neighbor) и соединяет границу в единый многоугольник. Ползунок «Упрощение (Ramer-Douglas-Peucker)» отсекает лишние точки на прямых участках, обеспечивая идеальный FPS без тормозов физического движка.

⚙️ Настройки контура

Порог альфа-канала (Alpha): 25
Игнорирует полупрозрачные пиксели/пух
Сглаживание / Упрощение точек (Tolerance): 3.5 px
Меньше значение = точнее форма, больше = меньше полигонов
Отступ контура (Offset/Padding): 0 px
Сузить или расширить хитбокс относительно спрайта
